The Jupyter Notebooks in this directory are made by
Doug Latornell for sharing of Python code techniques and notes.
They are confirming that the initial test runs on the new (in summer 2026) arbutus cloud have 
acceptable similarity to the runs on the previous arbutus cloud.

The links below are to static renderings of the notebooks via
[nbviewer.org](https://nbviewer.org/).
Descriptions below the links are from the first cell of the notebooks
(if that cell contains Markdown or raw text).

* ## [nowcast-blue-check.ipynb](https://nbviewer.org/github/SalishSeaCast/analysis-doug/blob/main/notebooks/arbutus-2026-eval/nowcast-blue-check.ipynb)  
    
    **Check New `arbutus.cloud` Results of `nowcast-blue` Run**
    
    Compare results of a SalishSeaCast v202111 `nowcast-blue` (physics-only) run from the 2026 `arbutus.cloud`
    to one from the pre-2026 `arbutus.cloud`.
    
    The 2026 `arbutus.cloud` run uses builds from newer compilers and libraries (Ubuntu 24.04) and runs on fewer nodes.
